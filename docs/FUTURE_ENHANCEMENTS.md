# Future Enhancements

The following features are intentionally outside the current MVP scope.

## 1. Waitlist

Implement a FIFO waitlist when an event reaches capacity.

## 2. QR Invitations

Generate event-specific QR codes for invitations or check-in.

## 3. Notifications

Add email, push, or SMS notifications for:

-   RSVP confirmation
-   Event reminders
-   Announcements
-   Cancellation
-   Waitlist promotion

## 4. Advanced Analytics

Add:

-   RSVP conversion rate
-   Attendance trends
-   Registration timeline
-   Event popularity
-   Exportable reports

## 5. Admin Dashboard

Add administrative functions such as:

-   User management
-   Event moderation
-   System statistics
-   Audit logs

## 6. Dedicated REST API

Move selected business operations behind a backend service for:

-   Centralized validation
-   Rate limiting
-   Trusted role enforcement
-   External integrations

## 7. Automated Testing

Add:

-   Unit tests
-   Component tests
-   Integration tests
-   Firestore security-rule tests
-   End-to-end tests

## 8. Production Deployment

Deploy the frontend and configure production Firebase resources,
domains, environment variables, monitoring, and security controls.

## 9. Calendar Integration

Allow users to export or synchronize events with calendar platforms.

## 10. Event Media

Add event image upload using cloud storage.

## 11. Audit Logs

Record important organizer and system actions for traceability.
