# User Guide

## Organizer Workflow

### 1. Register

Create an account and select the organizer role.

### 2. Login

Log in using the registered email and password.

### 3. Create an Event

Enter:

-   Event name
-   Description
-   Event type
-   Date
-   Start time
-   End time
-   Venue
-   Optional online link
-   Maximum capacity
-   Registration deadline

### 4. Manage Events

From the organizer dashboard, an organizer can:

-   View events
-   Edit events
-   Cancel events
-   Delete events
-   Open event details

### 5. Monitor RSVP Analytics

The event details page displays live:

-   GOING
-   MAYBE
-   NOT GOING
-   Total responses
-   Capacity
-   Remaining seats
-   Occupancy percentage

### 6. Publish Announcements

Organizers can publish announcements associated with an event.

They can also edit or delete existing announcements.

## Attendee Workflow

### 1. Register

Create an attendee account.

### 2. Login

Sign in to access the attendee dashboard.

### 3. Discover Events

Published events appear in the event list.

### 4. View Event Details

Open an event to see:

-   Date
-   Time
-   Venue
-   Organizer
-   Capacity
-   Registration deadline
-   Online meeting link when available
-   Live announcements

### 5. Submit RSVP

Select:

``` text
GOING
MAYBE
NOT GOING
```

The RSVP can be changed later.

### 6. Upcoming Events

Events for which the attendee has a GOING RSVP and which have not yet
occurred appear in the upcoming events section.

## Mobile Usage

On smaller screens, the navigation menu collapses into a hamburger menu.

The dashboard, event cards, forms, analytics, and event details adapt to
smaller screen sizes.
